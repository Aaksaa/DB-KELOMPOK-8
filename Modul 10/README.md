Repository ini menjawab untuk soal unjuk kerja dan lembar kerja pada modul 10 mata kuliah Basis Data.

Berikut detailnya:
# 1. Eksplorasi DBMS
[Detail](./1-Eksplorasi%20DBMS)

Mengidentifikasi RDBMS yang sedang digunakan (MariaDB/MySQL), mengecek versi dari RDBMS tersebut, serta mengidentifikasi storage engine yang digunakan (InnoDB).

# 2. Arsitektur Sistem
[Detail](./2-Arsitektur%20Sistem)

Menjelaskan tipe arsitektur yang dipakai (client-server berbasis web dengan pola MVC) beserta penjelasan komponennya, mulai dari presentation layer, application layer, hingga database layer.

# 3. Implementasi SQL
[Detail](./3-Implementasi%20SQL)

Melakukan implementasi DDL (Data Definition Language) untuk pembuatan struktur database keuangan UMKM, serta DML (Data Manipulation Language) untuk operasi CRUD (Create, Read, Update, Delete) pada data.

# 4. Pengujian Integritas
[Detail](./4-Pengujian%20Integritas)

Melakukan pengujian integritas data menggunakan berbagai constraint seperti Primary Key (PK), Foreign Key (FK), dan aturan referensial (RESTRICT/CASCADE) untuk memastikan validitas dan konsistensi data.

# 5. Pengujian Transaksi
[Detail](./5-Pengujian%20Transaksi)

Menguji fitur transaksi pada database menggunakan perintah COMMIT dan ROLLBACK untuk memastikan operasi data berjalan secara atomic (berhasil seluruhnya atau gagal seluruhnya).

# 6. Analisis Performa
[Detail](./6-Analisis%20Performa)

Membuat data dummy dalam jumlah besar (simulasi database sungguhan), serta melakukan analisis performa query menggunakan perintah EXPLAIN untuk melihat eksekusi dan optimasi indeks.

# 7. Pemeliharaan
[Detail](./7-Pemeliharaan)

Melakukan backup (dump) dan restore ulang seluruh database (simulasi pemeliharaan database sungguhan) untuk menjaga keamanan dan ketersediaan data.
