Repository ini menjawab untuk soal unjuk kerja dan lembar kerja pada modul 10 mata kuliah Basis Data.

Berikut detailnya:
# 1. Eksplorasi DBMS
[Detail](./1-Eksplorasi%20DBMS)

Mengidentifikasi RDBMS yang sedang digunakan, mengecek versi dari RDBMS tersebut serta mengidentifikasi storage engine yang digunakan.

# 2. Implementasi CRUD dan Pengujian Integritas
[Detail](./2-Implementasi%20Integritas%20Basis%20Data)

Melakukan implementasi CRUD (Create Read Update Delete) pada data di dalam tabelnya serta melakukan pengujian integritas pada data.

# 3. Analisis Performa
[Detail](./3-Analisis%20Performa)

Membuat 1 juta data dummy (simulasi database sungguhan), serta penggunaan queri EXPLAIN, COMMIT dan ROLLBACK.

# 4. Backup dan Restore Database
[Detail](./4-Backup%20Restore)

Melakukan backup dan restore ulang seluruh database (simulasi pemeliharaan database sungguhan).
