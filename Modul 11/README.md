Repository ini menjawab modul 11 mata kuliah Basis Data menggunakan DBMS MySQL.

Berikut detailnya:
# 1. Dokumentasi (Perbandingan DBMS)
[Detail](./dokumentasi)

Berisi dokumen analisis dan perbandingan berbagai jenis Database Management System (DBMS), khususnya membandingkan MySQL (RDBMS) dengan pendekatan database lain beserta kelebihan, kekurangan, dan studi kasus penggunaannya.

# 2. Diagram
[Detail](./diagram)

Berisi rancangan skema dan diagram pemodelan data relasional maupun berorientasi objek yang digunakan sebagai acuan struktur database pada modul ini.

# 3. Implementasi SQL
[Detail](./sql)

Berisi kumpulan skrip query MySQL untuk pengerjaan modul, mencakup implementasi manipulasi tipe data JSON (operasi CRUD dan fungsi bawaan JSON) serta pemodelan berorientasi objek (*join* data objek-relasional dan pembacaan transaksi).

# 4. Assets
[Detail](./assets)

Menyimpan aset pendukung seperti tangkapan layar (*screenshot*) hasil eksekusi query dan gambar pendukung dokumentasi pengerjaan modul.
